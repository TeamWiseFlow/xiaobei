# 千帆合作 Workflow

适用：用户要寻找、评估千帆分销商并制定合作方案。研究和提案保存到 Workspace `xhs/cooperation/qianfan/<项目名>/`。

## 1. 定义分销目标

明确商品、供货与库存、目标类目、期望分销商规模、地域、佣金或分润范围、履约能力、合作时间和排除条件。未确定的商务条款标记待定，不猜测平台默认值。

## 2. 查找与尽调

```bash
xhs-qianfan check
xhs-qianfan categories
xhs-qianfan search --choice '-1' --count 20
xhs-qianfan profile '<buyer_id>'
```

`check` 被拒绝时停止。先按类目小样本筛选，再读取候选分销商的总览、历史合作品类、店铺、商品与粉丝数据。按商品匹配、渠道能力、合作记录、受众契合和潜在冲突做证据化评分；接口缺项保留“未取得”。记录采集时间与可用样本数。

## 3. 合作提案与执行出口

形成入围名单和每家的建议商品、供货条件、佣金范围、时间表、预期产出与风险。把提案交用户审核。当前 `xhs-qianfan` 只提供查询接口，没有平台发起合作的 API；用户选择目标后，按其指定的千帆页面或其他已授权渠道完成实际联络，并回填真实结果。不要把内部提案标成已邀约。
