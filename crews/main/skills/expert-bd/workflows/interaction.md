# 评论与私信互动 Workflow

适用：用户要求评论互动、发送私信/邮件或进行线索联络。按本包能力表选择平台和已实现接口；创作、发布与本人作品数据转对应平台专家包。

需要先找客户时，按本包 [Lead Hunting](lead-hunting.md) 获取候选与判定理由。已有明确目标时直接开始；expert-osbi 的研究证据也可作为联络依据。

1. 确定平台、真实目标、互动目的、确切文案与授权范围。没有发布/发送授权时只整理草稿；既有授权覆盖的动作无需重复确认。
   - 本次涉及合作洽谈、交易对手核验或尽调，需要补充企业背景时，先按下文“企业背景核验”执行，再据此准备联络文案；普通评论/私信不要求企业查询。
2. 用一级 `douyin-hunter` / `xhs-hunter` 获取真实作品、评论和账号资料，保留完整 ID、链接及小红书 xsec_token。用 bd-record 查重；错误与样本不足如实标注。
3. 读 `references/interaction-capabilities.md` 与目标工具说明。未实现的写操作报告缺口，不能将模拟预览当成功。
4. 生成预览，核对目标和文案后执行已授权动作。抖音文本直达使用 `douyin-im send-to --to-user-id <真实数字UID> --text "文案" --request-id <本次任务稳定编号>`，脚本内部复用/建立会话并保存发送回执；重试复用同一编号，结果未知时停止重发；小红书使用 `xhs-im send <用户ID> "文案"`。预览后实际执行加 `--confirm`，不让 agent 手工拼接中间会话文件。
5. 抖音公开评论使用 `douyin-interact comment --url <作品链接> --text "文案"`；回复使用 `reply --comment-id <真实评论ID>`。小红书笔记评论接口尚未实现；不要调用直播评论命令代替笔记评论。
6. 小红书私信查询用 `xhs-im list/history/unread`，需要标记已读、撤回或删除时用 `read/revoke/delete` 先预览；群聊只查询。结果不明先核对历史或平台页面，不自动重发。
7. 邮件联络按公共 email-ops 的实际配置与授权执行；主题、收件人与正文必须有明确依据。
8. 用 bd-record 记录真实目标、动作、时间和结果；邮件另在 Workspace `bd/` 保留联络日志，不强行写成平台帖子。区分已提交、已核实送达和失败；汇总真实回复、待跟进及能力缺口。没有用户要求不建立周期任务。

直播间提问、答疑与合作互动按 [Live Interaction](live-interaction.md) 执行；竞争对手直播调研交 expert-osbi 的 Live Research workflow。取数、登录失效或风控不触发重新发布内容。

TikTok 互动通过 tiktok-interact/tiktok-im/tiktok-live，写操作需要同次 ticket-guard 材料。X 评论、回复、点赞、转发、收藏与关注使用 twitter-interact；twitter-im 只查询首页会话及加密占位历史。所有写操作先预览，已有授权时 --confirm；快手只支持直播观察，没有评论、点赞、关注、私信或直播发言接口。

YouTube 评论/回复、点赞、稍后观看和订阅使用 youtube-interact；直播文字聊天使用 youtube-live。登录由 youtube-hunter 管理，评论与直播发言需有频道；公开读取走 youtube-hunter。未知结果先核查，不重发；无私信或送礼支付能力。

## 企业背景核验（按需）

使用天眼查 `tyc` 前，遵循本包 [SKILL.md 的安装与授权规则](../SKILL.md#安装与授权规则)：先检查本机；已安装直接复用，不重复提示；未安装时先展示免费额度与计费规则，再询问是否同意安装，得到同意后才安装。

以已确认的企业全称或统一社会信用代码查询。以下命令各自独立，按联络目的选用；将示例企业替换为真实目标：

```bash
# 核对拟合作或交易主体的工商登记
tyc company registration-info "乐视网信息技术（北京）股份有限公司" --head 80

# 核对经营、司法等基础风险摘要
tyc risk overview "乐视网信息技术（北京）股份有限公司" --head 80
```

优先复用 Lead Hunting 已取得的本轮资料，查询时间、主体或核验范围不满足本次任务时才补查。企业与实际联系人之间的关系需另有依据，不凭公司查询结果确认某人的任职或联络身份。来源、查询时间、结果和未核实项存入 Workspace `bd/` 联络资料；额度不足、无权限或无数据如实标注，不视为已通过核验。`--head` 仅限制终端展示，需要完整结果时按 SKILL.md 在同一次查询中保存。企业核验不改变已有发送授权范围。
