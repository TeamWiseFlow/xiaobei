# Style DNA
明确目标 DNA 与视频/文字图文类型，用 kuaishou-hunter 获取正文、作者、指标和有序媒体，保存到 kuaishou/ref/<样本>/。视频调用 viral-chaser，逐帧回读与核对转写；图文回读每张图片，文字阅读完整帖串并记录覆盖。为每篇保存带来源、采集时间、真实计数与缺项的样本文字稿，然后用 kuaishou-style-profiler report。逐维写定性依据，不能只用统计 scaffold。对标样本建立独立 DNA，按明确 focus 借鉴。用 build 聚合全部报告并完善 DNA 文档与 template，写明分母、共性、孤例和用户偏好；调整建议经用户确认后用 update 融合，保持模板能从 DNA 推导。
